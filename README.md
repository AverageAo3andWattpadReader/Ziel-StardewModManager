# Ziel-StardewModManager
Originally made for myself, This is very incomplete. every other mod manager didnt work out well for me.
Feel free to use(personally duh)
MAINLY A MOD UPDATER!!!

INFO:
Only has 3 main features:
1. Gets the list of outdated mods like this:
[SMAPI]    (xx) blah blah blah 1.1.1: https://www.nexusmods.com/stardewvalley/mods/xxxx (you have 1.0.9)
[SMAPI]    (xxx) blah blah blah 1.1.1: https://www.nexusmods.com/stardewvalley/mods/xxxx (you have 1.0.3)
[SMAPI]    blah blah blah for 1.1.1: https://www.nexusmods.com/stardewvalley/mods/xxxx (you have 1.0.0)
[SMAPI]    blah blah blah 1.1.1: https://www.nexusmods.com/stardewvalley/mods/xxxxx (you have 8.0.0)
more links....
and extracts the links
2. The extracted links will then be automatically opened
3. Replaces Old mods with new mods via file transfer

CONS: 
1. You have to click the download button manually for every mod you want to download though so that it wont mess up which version of the mod you want to download(like how theres options for diff versions of the mod ur downloading like if its AT or DGA or smth)
  >while making this I thought that it would be the best option if the mods ur downloading/updating often have different versions like me.
2. It may glitch a bit, but I have done like 3 test runs and it all went without a hitch so I think it would work good enough
  >if it does, you can config the cooldowns between each action on the auto open link feature.
3. upds only if someone reports a problem :(
4. might be un-organized sometimes
5. I dont know if it works on steam
6. separate folders

PROS:
1. no ads
2. customizable
